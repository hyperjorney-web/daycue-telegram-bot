# Content System

## Problem

The current bot logic is usable, but the copy still often sounds:

- robotic
- abstract
- too long
- too similar day to day

The solution is not more raw generation.

The solution is a controlled content system.

## Voice Goals

The bot should sound:

- warm
- modern
- short
- practical
- human
- quietly confident

It should not sound:

- clinical
- therapeutic
- mystical
- vague
- like generic AI writing

## Writing Rules

Use:

- short sentences
- concrete verbs
- real-life actions
- everyday language
- specific invitations
- copyable messages

Avoid:

- “support”
- “connection”
- “regulation”
- “tone”
- “window”
- “reduce friction”
- “hold space”
- “today the energy is aligned”

## Output Structure

Every daily message should use:

- `Today`
- `Do this`
- `Text her`
- `Avoid`
- `Extra`

The user should be able to skim it in under 10 seconds.

## Content Banks

We need four separate banks.

### 1. Today Cue Bank

Short actionable headlines.

Examples:

- Take one thing off her plate
- Don’t waste this good day on routine
- Keep tonight simple
- Give space without going cold
- Say the nice thing out loud
- Make the evening easier

### 2. SMS Bank

Actual messages a user would want to send.

Requirements:

- sounds natural
- copyable without editing
- not cheesy unless intentionally flirtatious
- no therapist tone

### 3. Avoid Bank

Concrete mistakes.

Examples:

- Don’t make her choose if she already looks tired
- Don’t start a heavy conversation late tonight
- Don’t be half-present on a warm day
- Don’t crowd her with questions

### 4. Practical Idea Bank

Real actions by context:

- at home
- together
- apart
- 5-minute version
- evening version
- weekend prep version

## Relationship Skill Cards

This is the main content unit.

Each card should include:

- `headline`
- `do`
- `say`
- `text`
- `avoid`
- `extra`

The card should map to a real human situation.

## Current Card Families

- recovery support
- body first care
- space without coldness
- soft validation
- reduce friction
- decision relief
- playful invitation
- initiative date
- warm appreciation
- steady presence
- repair after tension

## Needed Expansion

The next version should expand to:

- 50+ skill cards
- 120+ SMS lines
- 50+ avoid lines
- 60+ practical actions

## Anti-Repetition Rules

We should never repeat:

- the same headline two days in a row
- the same SMS family too often
- the same “avoid” wording inside a short window

Future rule:

- track last 7 used content ids
- avoid recently used items if other valid options exist

## Quality Standard

A good daily message should make the user think:

- yes, I could actually send that
- yes, that sounds like a real person
- yes, that’s specific enough to use

If it sounds like advice rather than a message, it is not good enough.
